# What is each dataset:
Below is a list of the datasets in the `data/clean` folder, along with their provenance and assumptions. Keep this up-to-date as you add new datasets or change existing ones.

### analysis_dataset.csv — [data/clean/analysis_dataset.csv](data/clean/analysis_dataset.csv)
  - Generated by: [notebooks/Shota Emoto/test_analysis.ipynb](notebooks/Shota%20Emoto/test_analysis.ipynb) by merging the PPI green-share panel with country resilience scores.
  - Analyzed in: [notebooks/Shota Emoto/test_analysis.ipynb](notebooks/Shota%20Emoto/test_analysis.ipynb).
  - Assumptions: country names are matched directly; missing resilience values indicate no match or no available country-level score.

## Country_level_green_data.csv — [data/clean/Country_level_green_data.csv](data/clean/Country_level_green_data.csv) (used to be named merged_policy_investment_scores.csv but renamed for clarity)
  - Generated by: [src\replicate_figure.py](src/replicate_figure.py) by merging the PPI green-share panel with country green policy scores.
  - Analyzed in: [docs\Analysis_Jun24.md](docs\Analysis_Jun24.md)
  - The file is referenced as input by [src/country_cluster_regression.py](src/country_cluster_regression.py) and [src/country_cluster_regression_multiple_k.py](src/country_cluster_regression_multiple_k.py). 
  - Assumptions: The results of the analysis for clean energy policies and investments.

## country_resilience_scores.csv — [data/clean/country_resilience_scores.csv](data/clean/country_resilience_scores.csv)
  - Generated by: [src/resilience_analysis.py](src/resilience_analysis.py).
  - Analyzed in: [docs/policy_classification_analysis_report.md](docs/policy_classification_analysis_report.md) and [notebooks/Shota Emoto/test_analysis.ipynb](notebooks/Shota%20Emoto/test_analysis.ipynb).
  - Assumptions: each country is counted once per unique policy after deduplication; a resilience score is the number of matching national policies in the 2014–2024 window based on the taxonomy in [mentges_ci_enhanced_climate_resilience_taxonomy.csv](data/clean/mentges_ci_enhanced_climate_resilience_taxonomy.csv).

## cpdb_resilience_annotated.csv — [data/clean/cpdb_resilience_annotated.csv](data/clean/cpdb_resilience_annotated.csv)
  - Generated by: [src/resilience_analysis.py](src/resilience_analysis.py).
  - Analyzed in: [docs/policy_classification_analysis_report.md](docs/policy_classification_analysis_report.md).
  - Assumptions: policies are deduplicated by policy_id; a policy is flagged as resilient if any underlying row matches the taxonomy terms. Differences with the _scores file are that the _scores file counts unique policies per country, while this file keeps all rows and flags each row as resilient or not.

## mentges_ci_enhanced_climate_resilience_taxonomy.csv — [data/clean/mentges_ci_enhanced_climate_resilience_taxonomy.csv](data/clean/mentges_ci_enhanced_climate_resilience_taxonomy.csv)
  - Generated by: external input used by [src/resilience_analysis.py](src/resilience_analysis.py); not generated by a script in this repo. Based on (between others) the Mentges et al. (2023) taxonomy of climate-resilience policies, with some additional pruning of broad terms. 
  - Analyzed in: [docs/policy_classification_analysis_report.md](docs/policy_classification_analysis_report.md).
  - Assumptions: the taxonomy terms are treated as keyword patterns for infrastructure-resilience policy matching after pruning broad, non-infrastructure terms.

## ppi_clean_project_level.csv — [data/clean/ppi_clean_project_level.csv](data/clean/ppi_clean_project_level.csv)
  - Generated by: [notebooks/Russell Tsai/01_ppi_cleaning.ipynb](notebooks/Russell%20Tsai/01_ppi_cleaning.ipynb).
  - Analyzed in: [notebooks/Russell Tsai/ppi_green_share_methodology.md](notebooks/Russell%20Tsai/ppi_green_share_methodology.md).
  - Assumptions: projects are classified as green or brown using exact technology-string matches; ambiguous cases are left as missing rather than forced into a category.

## ppi_green_share.csv — [data/clean/ppi_green_share.csv](data/clean/ppi_green_share.csv)
  - Generated by: [notebooks/Russell Tsai/01_ppi_cleaning.ipynb](notebooks/Russell%20Tsai/01_ppi_cleaning.ipynb).
  - Analyzed in: [notebooks/Russell Tsai/ppi_green_share_methodology.md](notebooks/Russell%20Tsai/ppi_green_share_methodology.md) and [notebooks/Shota Emoto/test_analysis.ipynb](notebooks/Shota%20Emoto/test_analysis.ipynb).
  - Assumptions: country-year green share is computed from clearly classified projects; the narrow and broad definitions differ only for ambiguous hydro/waste cases.

## ppi_resilient_project_level.csv — [data/clean/ppi_resilient_project_level.csv](data/clean/ppi_resilient_project_level.csv)
  - Generated by: [notebooks/Russell Tsai/02_ppi_resilient_cleaning.ipynb](notebooks/Russell%20Tsai/02_ppi_resilient_cleaning.ipynb).
  - Analyzed in: [notebooks/Russell Tsai/02_ppi_resilient_cleaning.ipynb](notebooks/Russell%20Tsai/02_ppi_resilient_cleaning.ipynb).
  - Assumptions: the project-level file keeps only non-ambiguous rows and attaches an is_resilient flag for downstream robustness checks.

## ppi_resilient_share.csv — [data/clean/ppi_resilient_share.csv](data/clean/ppi_resilient_share.csv)
  - Generated by: [notebooks/Russell Tsai/02_ppi_resilient_cleaning.ipynb](notebooks/Russell%20Tsai/02_ppi_resilient_cleaning.ipynb).
  - Analyzed in: [notebooks/Russell Tsai/02_ppi_resilient_cleaning.ipynb](notebooks/Russell%20Tsai/02_ppi_resilient_cleaning.ipynb).
  - Assumptions: this is a country-year panel where resilient share is aggregated from project-level classifications and used as the main outcome variable.
